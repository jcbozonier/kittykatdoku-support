Website privacy

This notice covers the KittyKatdoku support website operated by Justin Bozonier. It is separate from the privacy information for the forthcoming iPhone app.

Visiting this site

This website has no account system, advertising, contact form, or analytics scripts. Its images and styles are served from the same website; it does not embed third-party media or fonts.

The site is hosted on GitHub Pages. GitHub states that it logs visitors’ IP addresses for security purposes. See GitHub Pages data collection and the GitHub Privacy Statement.

Contacting support

The email links open your email application. If you send a support email, Justin receives your email address, message, and any attachments you choose to include through Gmail. Please send only what is needed to explain your question. For questions about a support message or to request its deletion, contact bojuapps@gmail.com.

Game privacy information

The current browser playtest stores progress and custom levels locally in your browser. The native iPhone release has not been submitted. Its app privacy information will be finalized after the iPhone build and its included services have been reviewed.
